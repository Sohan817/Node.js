# Node.js Learning Journey

My notes, exercises, and projects while learning Node.js, mostly through YouTube tutorials.

## Goals

- Understand how Node.js works (event loop, modules, async model)
- Build and deploy a REST API
- Get comfortable with the npm ecosystem and tooling
- Write tested, maintainable server-side JavaScript

## Roadmap

### 1. JavaScript Foundations
- [ ] ES6+ syntax (let/const, arrow functions, destructuring, spread)
- [ ] Promises and `async`/`await`
- [ ] Modules (CommonJS vs ES Modules)

### 2. Node.js Core
- [ ] What Node.js is, the V8 engine, and the event loop
- [ ] Built-in modules: `fs`, `path`, `os`, `http`, `events`
- [ ] Streams and buffers
- [ ] Environment variables and `process`

### 3. npm and Tooling
- [ ] `package.json`, scripts, and semantic versioning
- [ ] Installing and publishing packages
- [ ] `nodemon`, `dotenv`, ESLint, Prettier

### 4. Web Servers and APIs
- [ ] Building a server with the `http` module
- [ ] Express.js: routing, middleware, error handling
- [ ] REST API design and status codes
- [ ] Validation (e.g. Zod or Joi)

### 5. Databases
- [ ] MongoDB with Mongoose, or PostgreSQL with Prisma
- [ ] CRUD operations and data modeling

### 6. Auth and Security
- [ ] Password hashing (bcrypt)
- [ ] JWT and sessions
- [ ] CORS, Helmet, rate limiting

### 7. Testing and Deployment
- [ ] Unit and integration tests (Jest or Vitest, Supertest)
- [ ] Docker basics
- [ ] Deploying to a cloud host (Render, Railway, Fly.io, etc.)
